# 🔒 Security & Privacy

This repository is intended for educational purposes.

**Do NOT upload:**

- Real passwords
- API keys
- Access tokens
- `.env` files
- Private certificates
- University credentials
- Personal student information
- Private network information
- Sensitive database records
- Unauthorized vulnerability scan results

Use dummy data and authorized test environments for security experiments.
